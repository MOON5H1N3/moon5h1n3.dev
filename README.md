# moon5h1n3.dev

The website for [Unbinge](https://github.com/MOON5H1N3/Unbinge) and [Last Showing](https://github.com/MOON5H1N3/last-showing). It's generated by a small Python script with no dependencies, and Cloudflare Pages rebuilds it every time this repo changes.

| File | What it's for |
|---|---|
| `content.py` | Every word on the site: headlines, intros, install steps, FAQs. Most changes happen here. |
| `build.py` | The design: layout, colours and type for each page, from the two brand guidelines. |
| `common.py` | Shared pieces: structured data for search engines, sitemap, `llms.txt`, the FAQ markup. |

## Changing the site

**Words:** open `content.py` on GitHub, click the pencil icon, edit, and commit. The site updates itself about a minute later. Keep the quote marks and commas around each piece of text as they are. If a commit breaks the build, Cloudflare keeps the previous version live and shows the error in the project's Deployments list.

**Bigger changes:** ask Claude in a session with this repo attached. It can edit, check and push for you.

**Preview on your own computer** (needs Python 3):

```
python3 build.py preview preview
```

Then open `preview/index.html` in a browser.

## Cloudflare Pages settings

Connect the project to this repo (Workers & Pages, Create, Pages, Connect to Git) with:

| Setting | Value |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | `python3 build.py` |
| Build output directory | `dist` |

Then add `moon5h1n3.dev` under Custom domains, and switch on Web Analytics.

## Getting found

- Add the site to [Google Search Console](https://search.google.com/search-console) and [Bing Webmaster Tools](https://www.bing.com/webmasters) and submit `https://moon5h1n3.dev/sitemap.xml`. Bing feeds Copilot and ChatGPT search.
- Keep the app repos public and set each one's "Website" field to its page.
- When you change a page, update its date in `common.py` (search for `lastmod`) so search engines know to look again.
